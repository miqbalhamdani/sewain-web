# sewain-web

Frontend fase 1 Sewain — backoffice, halaman publik rental, portal penyewa.

Dibangun di atas [Horizon UI Chakra NextJS](https://github.com/horizon-ui/horizon-ui-chakra-nextjs)
(MIT, lihat `LICENSE`). Demo NFT marketplace dan RTL sudah dibuang; `admin/default`,
`admin/data-tables`, `admin/profile`, dan `auth/sign-in` ditinggal sebagai layar referensi
sampai layar aslinya menggantikannya.

```bash
npm install
npm run dev        # localhost:3000
npm run build
npm run typecheck
npm run lint
```
